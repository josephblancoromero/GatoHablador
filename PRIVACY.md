# Privacidad

GatoHablador no incluye telemetría ni analítica. El MVP no guarda registros de chat.

El addon presenta mensajes disponibles mediante la API de WoW como una matriz de píxeles. La aplicación procesa esa matriz localmente. Si en el futuro se incorpora un proveedor en línea, deberá ser opcional, estar desactivado por defecto y explicar qué texto se transmite y a quién.

No compartas una carpeta de datos futura sin revisar primero que no contenga conversaciones o credenciales.
