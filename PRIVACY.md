# Privacidad

GatoHablador no incluye telemetría ni analítica. El MVP no guarda registros de chat.

El addon presenta mensajes disponibles mediante la API de WoW como una matriz de píxeles. La aplicación procesa
esa matriz localmente. Al elegir Ollama, el texto se envía únicamente al servicio local en `127.0.0.1:11434`.
GatoHablador no incorpora proveedores en línea ni acepta direcciones remotas.

No compartas una carpeta de datos futura sin revisar primero que no contenga conversaciones o credenciales.
